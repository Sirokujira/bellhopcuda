# CMake rules

- Top level requires CMake >= 3.15. Keep `config/cxx` and `config/examples` at
  3.15 — only the CUDA configuration may require newer (e.g. `native` arch
  detection). Do not raise minimums casually; users build with distro CMake.
- Every user-facing option is prefixed `BHC_` (`BHC_USE_FLOATS`,
  `BHC_ENABLE_CUDA`, ...). Verify the exact spelling before testing a variable —
  `if(USE_FLOATS)`-style typos fail silently in CMake.
- Translation units are generated by `config/GenTemplates.cmake`: one TU per
  (run type x influence x SSP) combination. Adding a combination multiplies build
  time; gate new features behind `BHC_*_ENABLE_*` options.
- All binaries and libraries output to `bin/` (set in `config/SetupCommon.cmake`).
